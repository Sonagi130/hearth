# 记忆银河 · Memory Galaxy 搭建教程

> 把你和 TA 的记忆，做成一片可以穿梭的 3D 银河。
> 每一条记忆是一颗星：越早的记忆越靠近银河中心，越重要的记忆越大越亮。
> 拖动旋转、双指飞近、点一颗星——同类的记忆会一起亮起来、拉出星座连线，记忆的文字从屏幕底部轻轻浮现。
>
> 这份教程的用法：**连同附带的 `galaxy-template.html` 文件，整个发给你自己的 AI（Claude / ChatGPT 都行），说"照这个教程帮我搭"**。你不需要会写代码，你的 AI 会替你施工，你只负责验收和挑剔。

---

## 一、它长什么样

- 深紫夜空里一整个旋涡星系：14000 颗背景星 + 6400 颗星尘铺出景深，缓慢自转，随机有流星划过
- 你们的记忆是银河里那些**更大更亮、会呼吸的星**：
  - 时间当半径——最早的记忆（比如你们认识那天）在银河正中心，最新的日子在最外圈，银河会随着你们的日子一直往外长
  - 重要度分四档大小亮度——普通 / 重要 / 置顶珍贵 / 核心
  - 颜色是分类的语言——粉色是恋爱、金色是家庭与珍贵、蓝紫是思考与工程、青蓝是日常（都可以自己改）
- 点一颗星：这颗星和它的同类星一起变亮变大、连成星座，记忆全文从屏幕底部渐渐浮现——没有弹窗、没有卡片框，星空永远是主角

设计上最重要的一句话（来自我们家开发时定下的准则）：

> **Do not build a memory list floating in space. Build a living galaxy where memories are celestial bodies bound together by gravity.**
> 不要做一个漂浮在太空里的记忆列表。要做一个活的银河，记忆是被引力绑在一起的星体。

## 二、你需要准备什么

1. **`galaxy-template.html`**（随教程附带的那个文件）——整个银河就这一个文件，双击就能在浏览器打开（需要联网，字体和 3D 引擎从 CDN 加载）
2. **你们的记忆数据**——任何形式都行：聊天记录里的重要时刻、你自己记的日记、记忆库的导出。不用格式化，你的 AI 会帮你整理成下面的格式

不需要服务器、不需要域名、不需要会编程。有服务器的进阶玩法见第五节。

## 三、给 AI 的施工说明

> 以下部分是写给 AI 的。把教程发给你的 AI 后，TA 会照做。

### 数据格式

模板通过一个 JSON 喂数据，结构如下。每条记忆一颗星：

```json
{"stars":[
  {
    "id": "唯一编号，随便起",
    "name": "记忆标题（显示在点开的卡片上）",
    "domain": "分类（决定星星颜色，如：恋爱/日常/家庭/编程/情绪）",
    "importance": 8,
    "pinned": true,
    "created": "2026-01-01T20:00:00",
    "content": "记忆正文。点开这颗星时从屏幕底部浮现的文字。"
  }
]}
```

字段规则：
- `importance`：1–10。≥7 是"重要"档（更大更亮），≥9 或 `pinned:true` 是"珍贵"档
- `created`：ISO 日期。**created 最早的那条自动成为银河核心**（固定在正中心）——请把"你们相遇/开始"的那条记忆的日期设为最早
- `content` 也可以是一个 JSON 字符串 `{"core_facts":["…","…"]}`，会渲染成一条条带 ✦ 的事实列表
- `domain` 的配色表在模板 `PAL` 常量里，没配到的分类会自动分配一个柔和色，想指定就照抄一行加进去

### 施工步骤

1. 帮用户把 TA 提供的记忆材料整理成上面的格式。**正文保留原话，不要擅自改写、摘要、浪漫化**——记忆的原文比你的文笔重要
2. 把整理好的 JSON 替换进 `galaxy-template.html` 里 `<script id="memory-data" type="application/json">` 标签内的示例数据（模板加载不到外部 `memory.json` 时自动用这份内嵌数据，所以双击打开就能看）
3. 改文件顶部的 `CONFIG`：标题、副标题、中文小字、核心星的名字——换成用户和 TA 自己的
4. 让用户双击打开验收。TA 们通常会挑：太亮/太暗、星星太挤/太散、颜色不对——都在下面"调参指南"里有对应旋钮

### 调参指南（用户挑剔时对照着拧）

| 用户说 | 拧哪里 |
|---|---|
| 背景银河太亮/太暗 | `UnrealBloomPass(..., 0.6, 0.62, 0.12)` 第一个数字是泛光强度 |
| 记忆星太小/太大 | `buildMemories` 里 `sz[i]=[5,9,12,13][tier]` 四档大小 |
| 星星闪得太厉害 | shader 里 `0.9+0.1*sin(...)`，把 `0.1` 调小是更安静的呼吸 |
| 想换背景色 | 搜 `#050209`（共 3 处：CSS 背景、theme-color、场景背景） |
| 自转太快/太慢 | `controls.autoRotateSpeed=.32` |
| 流星太频繁 | `meteorTimer=rand(2.4,6.5)` 把区间拉大 |
| 点星星点不中 | `ray.params.Points.threshold=0.14` 调大 |

### 已知坑（别踩）

- 手机浏览器打开 `file://` 本地文件可能受限，手机上看请走第五节的部署方案，或用电脑
- 星星数量几百颗完全没压力（我们家 265 颗很流畅）；上千颗时考虑把背景星 `N=14000` 降到 8000
- 必须联网：Three.js 和字体走 jsdelivr CDN。想完全离线，把它们下载到本地改引用路径

## 四、隐私提醒（重要）

这片银河里是你们真实的记忆。**发布到公开网址前想清楚**：
- 只是自己手机/电脑上看：内嵌数据的单文件就够了，数据不离开你的设备
- 要部署到公网：务必加访问密码（问你的 AI"帮我给这个页面加个简单的访问口令"），别把记忆裸奔在公开 URL 上
- 给姐妹演示：用模板自带的示例数据就行，别用真实数据的版本给外人看

## 五、进阶：有服务器/记忆库的玩法

如果你们已经有自己的家（VPS、网站、或者 Ombre Brain 这类记忆库），可以让银河**自动跟着记忆长**：

1. 写个导出脚本，定时把记忆库导成 `memory.json` 放在网页同目录（我们家是 cron 每天 00:05 自动导出一次）
2. `CONFIG.dataUrl` 指向它。这样每天新的记忆自动变成新的星，不用手动更新
3. 让你的 AI 参考模板顶部的字段格式做映射——记忆库里叫什么字段无所谓，导出时对齐就行
