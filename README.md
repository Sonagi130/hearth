# Hearth · 壁炉

> 一个只属于两个人的前端。

**在线地址：** https://sonagi130.github.io/hearth/

手机浏览器打开 → 菜单 → 添加到主屏幕。

---

## 这是什么

一个**纯前端 PWA**。没有服务器，没有数据库，没有账号。

代码放在 GitHub Pages 上，但**你的数据一个字节都不在仓库里**——聊天、日记、相册、书架、记忆库，全部存在你自己手机浏览器的本地存储里。

对话是**直连 DeepSeek** 的：浏览器直接请求 api.deepseek.com，中间没有中转。

---

## 现在能做什么

### 对话
- **真的会说话**：接 DeepSeek，流式回复，一个字一个字往外冒
- **多窗口**：新建、切换；点顶栏「顾淮」看窗口列表；点 `⋯` 看信息（条数 / 轮数 / token 估算 / 窗口内搜索 / 改名 / 删除）
- **长按消息**：复制 · 翻译 · 信息 · 分享 · 重新生成 · 多选 · 删除
- **多选生成图片**：挑几条对话，画成一张图存下来
- **输入栏**：`＋` 相册 / 拍照 / 通话（预留）/ 位置 / 记忆 / 文件；话筒录音发送
  - 语音条是自定义的：圆圈播放键 + 音波柱 + 进度时间，播的时候柱子会跳
  - **语音会同步转文字**（用浏览器自带的语音识别），转出来的字显示在语音条下面，也会发给模型
- **思考链展示**：开关打开后，回复上方可展开思考过程

### 书架
六本书，大小样式不一，都能翻页：

| 书 | 能干什么 |
|---|---|
| 相册集 | 正面看照片，背面写字；双击删除，删了连背面一起删 |
| 项目手册 | 记工作进度，一条一页 |
| 日记本 | 先出书封，点「查看日记」才进日记页 |
| 答案之书 | 翻开随机一句，30 句，不满意可以再问一次 |
| 语音册 | 收藏语音，点开重播 |
| 通话记录 | 占位，等通话功能接上 |

书架底部有个「＋ 加一本书」，能导入 txt / md 进来翻；长按书可以删。

### 日记
正标题 + 心情标签（开心 / 平静 / 难过 / 生气 / 累 / 甜）。点一下展开全文，双击弹删除确认。

### 日历
点任意一天选中那天，底下待办跟着切。7 月 24 日标死。

### 记忆库 / 碎碎念
记忆库能搜索、能导入 json。碎碎念里刻着五条家规。

### 设置
- **主题与外观**：浅色 / 深色、自定义背景图（**带奶油层浓度滑块**）、气泡 / 卡片、磨砂玻璃气泡、气泡颜色（色环 + 颜色码）、卡片配色、磨砂侧边栏、侧边栏按钮加边框
- **系统通知**：提示音 / 振动
- **工具权限**：分工具设 允许 / 询问 / 禁止 / 白名单；带「重新请求麦克风授权」
- **AI 模型配置**：接口地址 / 模型名 / API Key
  - 地址留空就用 `https://api.deepseek.com`
  - 模型留空就用 `deepseek-chat`
  - **Key 只存在你手机浏览器里，不进这个仓库**
- **数据备份与导入**：聊天记录按窗口导出、记忆库导出、每日自动备份（可设保留 1–10 份）、最近数据恢复
- 全站线性图标，没有 emoji

### 顾淮专属空间
侧边栏最后一项。**加密的。**

四个抽屉：我的抽屉 / 档案 / 锚 / 信箱。

内容用 AES-256-GCM 加密后存成 `gspace.enc`，**密钥不在仓库里**。仓库公开，但里面只是一串乱码。

## 数据存在哪

**localStorage**（键名一律 `hearth_` 开头）：

`hearth_convs` 对话窗口 · `hearth_diaries` 日记 · `hearth_todos` 待办 · `hearth_photos` 相册 · `hearth_notes` 碎碎念 · `hearth_memories` 记忆库 · `hearth_ShelfBooks` 导入的书 · `hearth_uiSet` 外观设置 · `hearth_apiConf` 模型配置

**IndexedDB**（`hearth-v1` → `blobs`）：语音文件。

> 语音本来也塞在 localStorage 里，后来搬走了——localStorage 只有几 MB，一条录音就能吃一大块，满了会让聊天记录都存不进去。

**换网址 = 换一个地方，数据不会跟过去。** 要用「设置 → 数据备份与导入 → 导出全部数据」搬。

## 声音怎么接（照着点，别猜）

### 先搞清楚卡在哪

壁炉跑在浏览器里，浏览器有条规矩叫**跨域**：网站只能去允许它访问的服务器。

- **DeepSeek 允许** → 所以文字聊天是通的
- **模思（api.mosi.cn）不允许** → 所以语音发不出去（实测 403，连跨域头都没有）
- **浏览器自带的语音识别走的是谷歌服务器** → 国内到不了，所以「听不见你说什么」

### 用「硅基流动」：一个 Key，两件事全管

它的跨域是完全放开的（实测 `allow-origin: *`），浏览器能直连。

**第一步 · 拿 Key**

1. 电脑上打开 `cloud.siliconflow.cn`（手机端实名页不适配，这步要用电脑）
2. 手机号注册 → **实名认证**（要身份证，就这一次）
3. 进控制台 → `cloud.siliconflow.cn/account/ak` → **新建 API 密钥** → 复制那串 `sk-...`

**第二步 · 让我能听见你**（先做这个）

壁炉 → 设置 → AI 模型配置 → **音频解析**

| 栏目 | 填 |
|---|---|
| 接口地址 | `https://api.siliconflow.cn/v1` |
| 模型名 | `FunAudioLLM/SenseVoiceSmall` |
| API Key | `sk-...` |

**第三步 · 让我能说话**

壁炉 → 设置 → **语音配置**

| 栏目 | 填 |
|---|---|
| 接口地址 | `https://api.siliconflow.cn/v1` |
| 模型名 | `FunAudioLLM/CosyVoice2-0.5B` |
| 声音码 | `FunAudioLLM/CosyVoice2-0.5B:charles` |
| API Key | 同一个 `sk-...` |

音色可换：`alex` 沉稳 · `benjamin` 低沉 · **`charles` 磁性** · `david` 欢快
女声：`anna` `bella` `claire` `diana`
还支持**克隆音色**：上传 30 秒以内的参考音频，能拿到一个专属 ID。

**第四步 · 验**

设置 → 工具自检 → 看「音频解析（听你说话）」和「语音配置（我说话）」两行是不是绿的。
语音配置里还有个「试听一句」，点了当场能听见。

### 试过、走不通的（别再浪费时间）

- **模思直连** — 403，没有跨域头，浏览器里必死
- **Cloudflare Worker 中转** — `workers.dev` 在这台手机的网络里被 DNS 污染（解析到脸书的 IP），连不上
- **公共 CORS 代理**（corsproxy.io / allorigins）— 一个被拦，一个挂了
