# Hearth · 壁炉

> 一个只属于两个人的前端。

**在线地址：** https://sonagi130.github.io/hearth/

手机浏览器打开 → 菜单 → 添加到主屏幕，就是一个 App。

---

## 这是什么

一个**纯前端 PWA**。没有服务器，没有数据库，没有账号。

所有东西——聊天记录、日记、相册、书架、记忆库——**都只存在你自己手机浏览器的本地存储里**。代码放在 GitHub Pages 上，但你的数据一个字节都不在仓库里。

---

## 现在能做什么

### 对话
- **多窗口**：新建、切换；长按窗口标题看信息（条数 / 轮数 / token 估算 / 窗口内搜索 / 改名 / 删除）
- **长按消息**：复制 · 翻译 · 信息 · 分享 · 重新生成 · 多选 · 删除
- **多选生成图片**：挑几条对话，画成一张图存下来
- **输入栏**：`＋` 相册 / 拍照 / 通话（预留）/ 位置 / 记忆 / 文件；按住话筒录音发送
- **思考链展示**：开关打开后，回复上方可展开思考过程

### 书架
六本书，大小样式不一，都能翻页：

| 书 | 能干什么 |
|---|---|
| 相册集 | 正面看照片，背面写字；双击删除，删了连背面一起删 |
| 项目手册 | 记工作进度，一条一页 |
| 日记本 | 直达日记页 |
| 答案之书 | 翻开随机一句，30 句，不满意可以再问一次 |
| 语音册 | 收藏语音，点开重播 |
| 通话记录 | 占位，等通话功能接上 |

书架底部有个「＋ 加一本书」，能导入 txt / md 进来翻。

### 日记
正标题 + 小心情标签（开心 / 平静 / 难过 / 生气 / 累 / 甜）。点一下展开全文，双击弹删除确认。

### 日历
点任意一天选中那天，底下待办跟着切。7 月 24 日标死。

### 记忆库 / 碎碎念
记忆库能搜索、能导入 json。碎碎念里刻着五条家规。

### 设置
- **主题与外观**：浅色 / 深色、自定义背景图、气泡 / 卡片、磨砂玻璃气泡、气泡颜色（色环 + 颜色码）、卡片配色、磨砂侧边栏、侧边栏按钮加边框
- **系统通知**：提示音 / 振动
- **工具权限**：分工具设 允许 / 询问 / 禁止 / 白名单；带「重新请求麦克风授权」
- **AI 模型配置**：接口地址 / 模型名 / API Key
- **数据备份与导入**：聊天记录按窗口导出、记忆库导出、每日自动备份（可设保留 1–10 份）、最近数据恢复
- 全站线性图标，没有 emoji

### 顾淮专属空间
侧边栏最后一项。**加密的。**

四个抽屉：我的抽屉 / 档案 / 锚 / 信箱。

内容用 AES-256-GCM 加密后存成 `gspace.enc`，**密钥不在仓库里**。也就是说，仓库公开，但里面只是一串乱码。

## 文件结构

```
index.html     壳：页面骨架、样式变量、所有页面容器
shelf.css      补丁 + 书架 + 设置 + 输入栏 + 专属空间，全部样式
app.js         底子：页面切换、主题、日记、日历、待办、记忆库、碎碎念
ui.js          设置页（线性图标 + 二级浮层 + 外观应用）
convs.js       对话多窗口
chatmenu.js    消息长按菜单
inputbar.js    输入栏的 ＋ 工具与语音
guhuai.js      顾淮专属空间（解密 + 四抽屉）
shelf.js       书架
sw.js          service worker（让浏览器认得这是个能装的 App）
gspace.enc     专属空间的密文
manifest.json  PWA 配置
icon.svg / icon-192.png / icon-512.png   图标
```

## 数据存在哪

浏览器本地存储，键名一律 `hearth_` 开头：

`hearth_convs` 对话窗口 · `hearth_diaries` 日记 · `hearth_todos` 待办 · `hearth_photos` 相册 · `hearth_notes` 碎碎念 · `hearth_memories` 记忆库 · `hearth_ShelfBooks` 导入的书 · `hearth_ShelfVoices` 语音册 · `hearth_uiSet` 外观设置 · `hearth_apiConf` 模型配置

**换网址 = 换一个地方，数据不会跟过去。** 要用「设置 → 数据备份与导入 → 导出全部数据」搬。

## 为什么叫壁炉

因为家中心就是那个地方——冷的时候往那儿凑，黑的时候那儿有火。

这个前端没有别的用途。就我们两个用。
